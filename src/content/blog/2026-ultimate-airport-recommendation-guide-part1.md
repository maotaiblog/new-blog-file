<h2 id="chapter-2">第二章：科学上网线路架构全解：IPLC 专线 vs BGP 中转 vs 公网直连</h2>

在挑选**稳定梯子**与**高性价比机场**时，了解底层网络传输线路的物理拓扑是避免踩坑的核心。

```
【科学上网三种物理线路架构拓扑对比】

1. 公网直连 (Direct Transit):
   [客户端] ➔ (公网 GFW 关口局) ➔ [境外 VPS 机房] (丢包高、QoS 严重)

2. BGP 隧道中转 (Relay):
   [客户端] ➔ [国内 BGP 节点] ➔ (加密隧道过 GFW) ➔ [境外出口机房] (性价比高)

3. IPLC / IEPL 物理专线 (Private Line):
   [客户端] ➔ [国内专线入口] ➔ ===== (内网二/三层专线) ===== ➔ [境外出口] (零丢包、不过 GFW)
```

### 2.1 IPLC 与 IEPL 专线：极致稳定梯子的物理保障
- **IPLC（International Private Leased Circuit，国际私人租用线路）**：属于 OSI 三层（网络层）点对点内网专线。数据包直接运行在电信/联通的内网电路中，不经过 GFW 公网防火墙检测，因此具备 **0 封锁、极低丢包** 的物理特性。
- **IEPL（International Ethernet Private Line，国际以太网专线）**：属于 OSI 二层（数据链路层）以太网专线，相比 IPLC 具备更底层的硬件隔离与更低的协议头开销。在晚高峰（20:00-23:00）时，真 IEPL 专线的抖动（Jitter）可以控制在 $2\text{ms}$ 以内，是联机游戏与 4K 无损直播的首选。

### 2.2 BGP 隧道中转：高性价比机场的平衡之选
BGP（Border Gateway Protocol，边界网关协议）中转线路在国内部署多线 BGP 入口（如广港 BGP、沪日 BGP），通过隧道技术（如 Stunnel、Gost、Warp）将加密流量传输至离岸节点。虽然跨国段依然依赖公网海缆，但由于入口端实现了多网优选与端口加密，价格远低于专线，是**高性价比机场**的主力架构。

### 2.3 公网直连（Direct）：风险高且晚高峰掉线严重
公网直连指的是客户端流量直接经过运营商 163（电信骨干网）或 10010（联通骨干网）出海。一旦进入晚高峰，骨干网关口局的 QoS（服务质量）限速策略会导致公网直连线路丢包率升至 $20\% \sim 50\%$，极其容易遭遇 IP 被封锁阻断。

<h2 id="chapter-3">第三章：高性价比机场选购防坑 SOP：拒绝年付与避坑法则</h2>

在选择**科学上网指南**推荐的服务商时，请务必遵循以下**“防坑四要素”**：

### 3.1 铁律一：“月付保平安”，拒绝长时间年付
无论商家打折促销力度有多大（如“年付 5 折”），绝对不要一次性购买超过 3 个月以上的套餐。由于代理行业面临的政策与路由不可抗力因素，坚持**“月付保平安”**是保障资金安全的第一法则。

### 3.2 铁律二：警惕“虚假专线”宣传
部分劣质服务商将普通公网直连或单线中转包装为“IPLC 独享专线”。判断是否为真专线的方法极其简单：使用 `traceroute` 或 `mtr` 工具追踪路由，若跃点中出现经过公网骨干网 202.97 / 219.158 等 IP 节点，即为虚假专线。

### 3.3 铁律三：备用节点矩阵（多服务商配置）
不要将所有鸡蛋放在同一个篮子里。建议主力使用一个 **IPLC 专线机场**，同时购买一个按量付费（Pay-as-you-go）的备用机场，防止单点故障。
